# Project Setup Guide

## Prerequisites

### All Platforms
- Git
- IDE of choice

### Android (KMP)
- Android SDK (API 24+)
- Android Studio / IntelliJ IDEA

### iOS (KMP & Native)
- Xcode 15+
- iOS 15+
- Apple Developer Account

### Backend
- Java 11+
- Kotlin 1.9+
