# Significance tests — 2026-08-23 data

alpha = 0.05. Mann-Whitney U, two-sided, normal approximation with tie
correction, rank-biserial r as effect size. Generated by
`scripts/build-thesis-dataset.py`; do not hand-edit.

**Implementation validated** against the numpy/scipy results in
`../../extracted/stats_tests.md`: it reproduces both published tests
exactly (p = 1.175e-4, r = -0.580 and p = 5.573e-10, r = -0.933).
Shapiro-Wilk is not used — scipy is unavailable, and the original
analysis selected Mann-Whitney in both cases anyway.

Read the `interpretation` column before quoting any p-value. With
n = 50 per group a sub-millisecond difference is easily 'significant'.

## Caveat on the iOS-vs-Android rows

Those cross platform *and* instrumentation: Android is Macrobenchmark
`timeToInitialDisplayMs`, iOS is the `applicationLaunch` signpost, on
different devices (Pixel 8 / iPhone 16) and different OSes. Both bound
"process launch to first content frame", but they are different probes.
Android values were converted ms -> s.
